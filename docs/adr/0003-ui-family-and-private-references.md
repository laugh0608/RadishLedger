# ADR-0003 家族 UI 采用与私有参考边界

状态：已接受；视觉稿、实现和真机验证另取证。

日期：2026-10-12（Asia/Shanghai）。

## 背景

项目所有者要求调整 UI 规范：记账参考用于理解布局与交互，整体视觉采用 RadishX 中的 Radish 家族规范；私人截图含敏感金融内容，绝不能加入 Git 或公开展示。

原规范仅明确 Workbench 方向，缺少可执行的颜色、排版、组件和主要页面转译规则。需要同时明确参考的用途、MVP 范围和材料隐私边界。

## 决定

1. 以产品范围与领域模型决定能力和账务口径；私人参考只贡献一般布局 / 交互经验，不引入额外产品能力或个人数据。
2. 采用 family-ui `v26.7.3` 的 Workbench 方向：暖纸表面、墨字、灰玉品牌、墨蓝操作、赭石财务辅助，保持五类状态语义。
3. 本项目定义移动端逻辑尺寸、正文与金额层级、主题映射和页面结构。金融金额默认主文本色，支出不借 danger、收入不借 success；退款和负净支出保留真实含义。
4. 暗色提亮的主按钮使用深墨前景，必要文本使用可读次文本，避免机械继承低对比组合。组件仍需按实际背景和状态验证。
5. 私人原图及裁剪、缩略图、拼图、重命名、描摹、打码、OCR / 数据导出等衍生材料不得进入 Git、产品或公开交付；不保存原数据、文件指纹或可回溯索引。
6. 私人素材保持仓库外，仅在明确授权范围内观察。忽略 / 归档排除是误操作保护，不授权导入、云端上传、生图或训练。
7. 所有原型、视觉验收和公开示例使用重新构造且标注的合成数据；参考图不是可裁剪、描摹或替色复用的资产。
8. 家族规范是设计来源，不是运行依赖；不读兄弟目录来构建客户端，不回写 RadishX 的项目采用状态。

## 取舍与后果

原样沿用截图界面会混入敏感内容、外部品牌、额外功能和不适合本项目的导航。只换颜色又无法兑现家族字体、留白、组件、状态和隐私边界。故由本项目独立设计主要页面，再转译参考中的效率与阅读关系。

纸感采用颜色与排版表达，工作面不引入小票撕边、条码、贴图或装饰循环。手机端提高正文与触控尺寸，不直接搬入桌面密度和物理像素。

颜色数值与理论对比可核对，但不能证明整页、辅助技术或真实交互已通过。低对比前景选择在 Ledger 本地解决，不修改家族参考或静默改变其状态语义。

## 来源与验证

来源为 RadishX 的 family-ui 文字、tokens 和相关内部视觉参考，以及授权观察的私人记账 UI。仓库不记录私人素材路径、原图、文件清单或金融内容。

最终规则见 [移动端 UI 规范](../design/mobile-experience.md)。本批只验证文字、token 值映射、基础色对、参考排除和文档一致性；页面原型、Flutter 主题、两端交互及隐藏金额的辅助技术行为待实际证据。
