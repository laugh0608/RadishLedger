### 实现与边界

- 增加 `csv_undo` 类型与 Store 撤销入口。同一读取快照核对原导入 / 来源 / 当前修订 / 候选及额外历史，分别列出可处理、编辑 / 恢复、已删除、已撤销、未完成和跳过范围；证据损坏或未知关联字段明确拒绝。
- 不可外改的 Preview 接受严格升序显式集合，每个任务最多 1000 行、每批 1–100 行；登记固定确认集合与随机删除 operation / revision 身份。同 ID 不允许换计划，登记和每批提交都重检条件。
- IMMEDIATE 事务复用 `apply_write` 写正常删除修订、selected、outbox、sequence，与撤销行结果 / 回执 / 进度同事务提交。竞争拒绝整批；取消不撤回已完成批次，重开只列出状态，需显式恢复。提交后丢失确认按原回执查询 / 重试，即使后来显式恢复交易，也不能用旧重试再次删除新修订。
- 新增 schema `3` 实验创建入口，复用 v2 导入布局并增加撤销三表及行历史索引，完整 digest 覆盖新增状态。v1 / v2 继续按原能力打开，撤销入口拒绝旧格式，不自动升级、加表、覆盖或重建；原移动实验仍新建 v1。没有新增依赖、lockfile 或 ABI 变化。
- 原导入任务、来源、行与批次保留；稳定来源重导及原导入重试不复活。无来源 ID 继续以原任务防重，新计划必须显式确认，不以内容 hash 自动删重。账户 / 分类及归档状态保留。
